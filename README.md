# 十二面骰子 · 十二地支

> 单文件 3D 十二面骰子（正十二面体）网页应用，骰面为十二地支（子丑寅卯辰巳午未申酉戌亥）。点击「摇一摇」，骰子在屏幕中弹跳旋转、随机停在某一面，平移到中央展示卜得的地支。

## 功能

- 🎲 正十二面体 3D 骰子，12 个面分别对应十二地支
- ✨ 「摇一摇」随机卜得一卦：弹跳 → 减速旋转 → 停面 → 平移到中央展示
- 📱 响应式布局，竖屏 / 横屏下骰子均不出视野
- 🎨 米白纸质质感 + 微粒背景，毛笔字风格地支

## 快速开始

无构建、无依赖安装。仅需：

1. **联网**（Three.js 通过 CDN 加载）
2. 通过 **HTTP** 打开（ES Module import map 限制，不能直接 `file://` 双击）

任选一种方式启动本地静态服务器：

```bash
# Python
python -m http.server 8000

# 或 Node
npx serve .
```

然后浏览器访问：**http://localhost:8000/骰子.html**

## 使用

打开页面后点击底部「摇一摇」按钮，骰子开始摇动并最终停在某个地支面，下方显示卜得结果。

## 实现要点

全部代码集中在 `骰子.html` 的单个 `<script type="module">` 中：

- **面数据提取**：从 `DodecahedronGeometry` 的顶点还原 12 个面的中心、法线与「朝上」方向。
- **面对齐四元数 `alignQuat()`**：让任意指定面正对相机且文字正立，是摇骰结果确定性的核心。
- **贴字纹理 + UV 重映射**：Canvas 2D 逐字生成纹理，并把默认极坐标 UV 改写为正五边形 UV，确保每面完整显示一个字、无扭曲。
- **摇骰动画**：位置（向心式 Catmull-Rom 弹跳样条）、对齐（slerp）、自旋（整数圈 + easeOutCubic 单调减速）三条轨迹叠加；收尾原地停留后纯平移到中央展示。
- **渲染状态机**：平时持续渲染，摇骰期间由动画帧独占，结束后重启循环，互斥管理两个 `requestAnimationFrame` ID。

> 详细的架构与修改注意事项见 [`CLAUDE.md`](./CLAUDE.md)。
